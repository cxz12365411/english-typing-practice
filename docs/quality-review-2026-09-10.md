# 英语打字练习项目检查与修复记录

检查基线：`c01a48c`；日期：2026-09-10。

本轮检查覆盖认证和账号隔离、练习与错题同步、管理员题库与 CSV、浏览器异步状态、依赖和服务器运维。修复保留当前数据库 schema 3，不修改词库种子、账号密码、站点地址和邮件开关。

## 已确认并修复

| 范围 | 触发情形与影响 | 修复 |
| --- | --- | --- |
| 练习控件 | 答对一题后分类、顺序及重来按钮持续禁用 | 每道题恢复与当前提交状态一致的控件状态 |
| 页面切换 | 旧答题请求、创建轮次请求或延时跳题返回时，页面已离开或重新打开 | 所有相关回调核对原页面状态，过期响应不再写入新页面 |
| 未同步答案 | 点击当前导航链接会重建页面，丢弃待重试答案 | 同路由导航不重建；原幂等请求保留 |
| 计时 | 同一题多次错答重复计算前面的用时；长时间挂机使提交超过 API 上限 | 每次已确认提交重新起算，提交和结束时间符合协议范围 |
| 服务端耗时 | `finish(durationMs=0)` 可以清零已经累计的耗时 | 结束操作不得降低已记录耗时 |
| 错题一致性 | 同毫秒乱序答题会让连击/首次正确率与错题状态矛盾 | 使用统一排序确定最后一次答题 |
| 草稿隔离 | 管理员编辑错题为草稿后，学员错题接口仍返回未发布的新内容 | 错题查询和计数仅显示已发布题目/分类，历史进度仍保留 |
| 无变化保存 | 未改动内容就保存或再次发布，会把题目转草稿或制造新修订 | 无变化更新和重复发布保持幂等 |
| CSV 发布 | CSV 可以发布到未发布分类 | 预览与提交两阶段都检查分类发布状态 |
| CSV 并发 | 旧预览可覆盖之后编辑的题目，或覆盖后来创建的同键题目 | 预览记录题目 ID 与 revision，提交不匹配时整批回滚 |
| CSV 校验 | 空数据或重复列名会被接受 | 返回预览错误，不执行导入 |
| 验证码 | 刷新会话或另一标签页获取会话会使现有验证码绑定失效 | 签名访客会话保留稳定的随机身份，同时续期 cookie |
| 账号验证 | 已登录状态下重复猜测当前密码没有持久限流；无关浏览器可消耗目标邮箱验证次数 | 密码验证增加账号/IP限流；邮箱验证码验证限额按访客会话隔离，真实与伪挑战同等处理 |
| 邮箱表单 | 请求验证码时更改邮箱，旧挑战仍回填；绑定成功后界面不更新 | 废弃过期请求结果；绑定后即时显示邮箱及改密表单 |
| 跨标签页身份 | 检测到账号变化时，旧页面可能持有新账号 CSRF 并继续操作 | 身份检查先于应用新 token，并同步恢复页面身份 |
| 管理后台 | CRUD/刷新/CSV 的慢响应可写入另一个后台页面或覆盖较新结果 | 页面与视图状态校验、请求顺序控制和 CSV 预览失效检查 |
| 内存数据库 | `:memory:` 被转为普通绝对路径 | 保留 SQLite 内存数据库专用值 |
| 定期清理 | 清理异常可能使进程退出；活动轮次的旧明细可能提前删除 | 捕获并记录清理异常；完成轮次后再删除过期明细 |
| 运维配额 | 超长十进制数在 Bash 中溢出，通过预检但应用拒绝启动 | 算术前验证有效十进制位与范围 |
| 备份恢复 | 只读 WAL 快照仍产生 sidecar；中断窗口可能留下错误完成标记 | 闭合快照使用 immutable 读取，清理自身临时文件，原子发布完成标记 |
