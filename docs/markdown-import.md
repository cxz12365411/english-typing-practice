# Markdown 题库导入与按文件练习

## 使用方法

1. 管理员进入“批量导入 → Markdown”，或从“题库管理”点击“从 MD 导入”。
2. 上传、拖入一个 `.md` / `.markdown` 文件，或粘贴 Markdown；文件/粘贴后自动预览。
3. 查看每条题目的英文、中文、谐音、分类、类型和操作结果。可把分组映射到已有分类，或确认待新建分类。
4. 修改文本或映射后，点击“重新校验并预览”。只有整批无错误且有可练题时才能继续。
5. 点击“导入并发布，开始练习”。新题进入账号版公共题库；当前页面仅练习本次文件中的可用题目。

不自动翻译，不生成谐音，不需要 AI 密钥。文件需包含英文及中文释义；谐音缺失会提示并保留为空。
UTF-8（可带 BOM）、Windows/Unix 换行均支持；每次最多 1 MiB、5000 条。

## 推荐模板

```markdown
# 日常练习
## 句型：街头摄影
| 英文 | 中文释义 | 中文谐音 |
| --- | --- | --- |
| My camera is ready. | 我的相机准备好了。 | 买 卡梅若 伊兹 瑞迪。 |

## 单词：摄影词汇
- **camera**：相机
  - 中文谐音：卡梅若
```

也兼容现有句型表格（英文格内 `<br>中文谐音：…`）和原始街拍段落：

```markdown
## 街拍交流
### 1. 自我介绍
**I'm a street photographer.**
中文：我是一名街头摄影师。
谐音：艾姆 额 斯垂特 佛塔格若弗。
```

二级标题用于分组；三级标题仅为说明。没有二级标题时使用一级标题，再依次使用文件名、手填分类名。
新分组默认按内容结构确定单词/句型，标题中的明确类型优先，预览可修改。表格按字段名识别，支持英文别名；
内容中的竖线写作 `\|`。`Stable ID` 列仅作为兼容元数据忽略，文件不能指定或覆盖数据库题目 ID。
链接、HTML、脚本均为文本，不执行、不访问；说明和代码围栏会被忽略并计数。可识别但损坏的题目报行级错误。

## 重复、发布与隐私

- 按最终分类、类型和规范化英文去重；保留大小写/空格/弯引号规范化规则，标点仍参与区分。
- 文件内重复保留首次；已有题目复用原内容，不更新原释义、谐音、排序或 revision。
- 仅有草稿/下架匹配时跳过，不恢复发布，也不加入本次练习。已有未发布分类须先在题库管理处理。
- 新分类与新题在同一事务发布；发生格式、权限或并发冲突时整批不写入。
- 全部重复且有已发布题时仍可练习，不增加题库版本。网络失败后重试同一次提交不会重复导入。
- 原始文本不长期保存；预览最长 30 分钟，成功提交时清除临时题目负载。独立批次只保存文件名、题目关联、归属和结果。
- 发布题目供账号版学员访问；`/practice?batch=…` 仅导入者可读取，其他用户得到 404，不泄漏文件内容。
- GitHub 免登录站和它的发布分支不修改，不自动公开上传文件或新增内容。

## 批次练习

批次保持文件顺序；刷新以及顺序/随机/错题切换不离开文件范围。重复项使用原题目 ID，因此原学习记录继续有效。
题目或分类被下架后立即不能提交新答题，重新加载批次时自动排除；没有可练题时显示空状态，不回退全库。
切换批次和退出批次仍会保护尚未同步的答案。点击“退出本次文件练习”可回到普通题库。

## 接口与上线

- `POST /api/admin/markdown-imports/preview`：Markdown、文件名、备用分类名、分组映射；返回 30 分钟预览及行级问题。
- `POST /api/admin/markdown-imports/commit`：仅接收 `previewId`；返回批次和新增/复用/跳过数量，成功重试返回同一批次。
- `GET /api/practice/import-batches/:id`：仅归属账号读取当前可练题，按文件顺序返回。
- `POST /api/practice/sessions`：可选 `importBatchId`，与 `categoryId` 互斥；服务端在会话创建及答题时检查归属、成员与发布状态。

数据库迁移 4 新增批次、成员关系及预览格式标识，不修改历史迁移 SQL。CSV 继续使用原接口并隔离 Markdown 预览。
上线沿用 `deploy/README.md` 的受保护版本化部署；迁移前先备份。旧版本不兼容 schema 4，失败回滚须同时恢复迁移前数据库，
不能仅切换 `current` 或使用 `--keep-database`。恢复备份会撤销其后的新活动，正式恢复前按现有运维手册执行。

只有受权服务器管理通道连通后才发布。连接失败时不更改防火墙、安全组、密码或其他网站，也不宣称本功能已经上线。
